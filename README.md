You can find these configuration keys across three different platforms: the Google AI Studio, your Firebase Console, and your own hosting provider.
Here is exactly where to locate each key, grouped by where they live.

🧠 Google AI Studio

• GEMINI_API_KEY: Log in to the Google AI Studio. Click on the Get API key button in the top left or top right corner. You can create a new key or copy an existing one there.

🔥 Firebase Console

All keys starting with VITE_FIREBASE_* come from a single configuration block in your Firebase project.
1. Go to the Firebase Console.
2. Select your project.
3. Click the Gear icon (Project settings) next to "Project Overview" in the left sidebar.
4. Scroll down to the Your apps section. If you haven't created a web app yet, click the </> (Web) icon to register one.
5. Under SDK setup and configuration, select the Config radio button. You will see a JavaScript object containing almost all your keys:
• VITE_FIREBASE_API_KEY: Found as apiKey in the config object.
• VITE_FIREBASE_PROJECT_ID: Found as projectId in the config object.
• VITE_FIREBASE_APP_ID: Found as appId in the config object.
• VITE_FIREBASE_AUTH_DOMAIN: Found as authDomain in the config object.
• VITE_FIREBASE_STORAGE_BUCKET: Found as storageBucket in the config object.
• VITE_FIREBASE_MESSAGING_SENDER_ID: Found as messagingSenderId in the config object.
• VITE_FIREBASE_MEASUREMENT_ID: Found as measurementId in the config object (only present if Google Analytics is enabled).

📍 Special Firebase Keys (Not in the main config block)

• VITE_FIREBASE_FIRESTORE_DATABASE_ID: If you are using the default Firestore database, this is usually just (default). If you created a named database, go to Firestore Database in the left menu; the ID is listed at the top of your database page.
• VITE_FIREBASE_OAUTH_CLIENT_ID: Go to Project Settings > Service accounts tab. At the bottom, click the Google Cloud Platform API Console link. In the GCP Console, go to APIs & Services > Credentials. Look under the OAuth 2.0 Client IDs section.

🌐 Your App Deployment

• APP_URL: This is the URL where your frontend application is hosted (e.g., http://localhost:5173 during local development, or https://vercel.app once deployed to production). You define this yourself based on where your code is running.

• Your APP_URL is generated by Firebase Hosting itself.
1. Open the Firebase Console.
2. Select your project and navigate to Hosting in the left sidebar menu.
3. Under the Domains section, you will see your default live URLs (usually ending in .web.app or .firebaseapp.com).
4. Copy the primary production domain (e.g., https://web.app)—this is your APP_URL.
